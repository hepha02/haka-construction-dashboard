# HAKA Construction Admin

공사비 관리용 관리자 대시보드입니다.

## 개발 및 검증

```powershell
npm ci
npm test
npm run dev
```

샘플 미리보기: `http://127.0.0.1:5173/haka-construction-dashboard/?preview=1`.
이 모드는 Supabase 클라이언트를 생성하지 않으며, 입력/승인/이체 상태 변경은 메모리의 샘플에만 반영됩니다. 새로고침하면 초기화됩니다.

## 운영 데이터 보존

- 운영 프로젝트는 실무자가 계속 사용하는 상태입니다. 개발 중 운영 DB에는 읽기 전용으로 접근합니다.
- 기존 데이터에 `supabase/schema.sql`을 다시 실행하거나 초기화/시드/복원 명령을 적용하지 마세요.
- 백업 파일은 `.private-backups/`에 보관하며 Git 및 웹 배포에 포함하지 않습니다.
- DB의 물리 백업과 별도로 업무 데이터 JSON과 Storage 원본을 복사합니다. JSON 내보내기는 DB 전체 복원본을 대체하지 않습니다.
- `node scripts/verify-backup.mjs <백업폴더>`는 파일 수·크기·SHA-256을 검증합니다. 전체 DB 복원 검증과는 다릅니다.
- 변경은 검토용 브랜치에서 준비하고, 운영 반영 직전에 최신 백업 및 신규 입력 내역을 재확인합니다.

## 집계 기준

승인 공사비는 승인된 신청 금액의 합계입니다. 송금완료 원가, 원천징수, 실지급액과 미송금 승인액을 구분합니다. 기존 장부 품목 원가는 별도 집계 기준으로 조회하며 결제 금액과 합산하지 않습니다. 기간은 신청일 기준입니다.

사업소득 3.3% 건은 아마란스 신고 확인 알림만 제공합니다. 신고서 작성이나 신고완료 추적은 수행하지 않습니다.

## 개발 환경 연결

필요한 경우 별도 개발 프로젝트의 연결 값을 로컬 `.env`에 넣습니다. 서비스 역할 키는 브라우저 코드에 넣지 않습니다.

```env
VITE_SUPABASE_URL=your-project-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```
